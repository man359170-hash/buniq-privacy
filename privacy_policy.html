Privacy Policy for bunIQ

Item Name: bunIQ  |  Extension ID: hbapijgmpokmjnoafooocacclfoekiek  |  Last Updated & Effective Date: September 25, 2026

This Privacy Policy governs the manner in which the bunIQ browser extension ("bunIQ", "we", "our", or "the extension") handles user privacy. bunIQ is a marketplace analytics, sales velocity calculator, and AI research productivity tool specifically designed for digital creators, educators, and sellers on ye-buna.com.

Core Privacy Commitment: bunIQ operates on a strict privacy-first, client-side architecture. We do NOT collect sensitive personal data, we do NOT maintain remote user tracking databases, and we do NOT sell, lease, or monetize your information to any third party under any circumstances.

1. User Data Collection

bunIQ collects and accesses only the minimum data necessary to deliver its core analytics and AI features:

A. User-Provided Information (Voluntary):

  • Community Profile Handle (Optional): During optional onboarding, users may input a public Telegram username (e.g., @username) to personalize their local community status. Providing this handle is voluntary, and it is stored exclusively within your local browser storage.
  • Personal Google Gemini API Key (Optional): If you choose to use the AI Product Studio, you may input your personal Google Gemini API key in the extension settings. The key is stored solely on your local device.

B. Public Marketplace Information:

  • ye-buna.com Public Listing Data: When you browse ye-buna.com, the extension inspects publicly visible product listing attributes (product titles, public category names, prices in ETB, public sales counters, and public MongoDB creation timestamps embedded in listing URLs). This is public commercial information and contains no personal identity data.

C. User Interface Preferences:

  • Display Settings: The extension stores your chosen theme (Dark Mode / Light Mode), language choice (English / Amharic), and in-page HUD overlay visibility preference.

D. Information We NEVER Collect:

  • We do NOT collect personal identification information (real name, home address, personal phone number, national ID).
  • We do NOT collect passwords, authentication tokens, or login credentials.
  • We do NOT collect financial or payment information (no credit/debit card details, banking credentials, or Telebirr PINs).
  • We do NOT collect health, biometric, or precise geographic location data.
  • We do NOT collect general web browsing history, search logs, or activity across any website other than ye-buna.com.

2. User Data Handling and Usage

We process data solely for the following explicit, single-purpose functions:

  • Sales Velocity & Outlier Computation: Listing timestamps and sales numbers extracted from ye-buna.com are processed entirely within your local browser memory using JavaScript to calculate daily units sold, velocity metrics, and statistical outlier multipliers (e.g., 3x Rising, 15x High, 50x Mega Outlier).
  • AI Product Generation (On-Demand): When you explicitly request an AI gap analysis, course blueprint, or ad copy inside the AI Studio, the selected product's public title and parameters are packaged into a prompt and transmitted directly to the Google Gemini API using your personal API key.
  • Preference Retention: Your chosen UI theme, language, and toggle preferences are retrieved at runtime to maintain your customized interface.
  • No Unrelated Handling: User data is never used for behavioral profiling, consumer creditworthiness assessments, surveillance, advertising retargeting, or any purpose unrelated to the stated single purpose of bunIQ.

3. User Data Storage, Retention, and Security

bunIQ enforces strict data storage and retention boundaries:

  • Local Device Storage Only: All user settings, community handle, preferences, cached marketplace velocity data, and your optional Google Gemini API key are stored locally in your browser sandbox using Chrome's native chrome.storage.local API.
  • No Remote bunIQ Servers: bunIQ does not operate, maintain, or transmit data to any proprietary centralized tracking server, external user database, or telemetry platform.
  • Data Retention Period: Data remains stored locally on your device only for as long as you maintain the extension installed. Once you clear data or uninstall the extension, all locally stored data is permanently deleted.
  • Data Security: By confining all storage to the browser's protected local storage mechanism, your data is isolated from other websites and extensions. Any external communication with the Google Gemini API is conducted over encrypted, industry-standard HTTPS / TLS (Transport Layer Security) connections.
  • User Data Deletion: You can completely erase all stored preferences, cached metrics, and your saved API key at any time by clicking the "Reset" button in the extension footer/settings, or by removing the extension via chrome://extensions.

4. User Data Sharing and Third-Party Disclosure

We maintain an uncompromising stance on data sharing:

  • Zero Data Selling: We do NOT sell, rent, trade, monetize, or license your data to any third party, data broker, advertising network, or marketing agency under any circumstances.
  • Direct AI API Provider (Google Gemini): When you choose to utilize the bunIQ AI Studio with your personal Google Gemini API key, your prompt text is transmitted directly from your browser to Google's API endpoint (https://generativelanguage.googleapis.com). bunIQ does not act as an intermediary, proxy, or logger for these requests. Google processes this data in accordance with the Google Privacy Policy.
  • No Third-Party Analytics / Tracking Scripts: bunIQ contains no third-party tracking scripts, no Google Analytics, no Facebook Pixels, and no ad SDKs.
  • Legal Disclosures: Because bunIQ does not store or collect user data on any remote server, we possess no user data to disclose to third parties, law enforcement, or government agencies.

5. Browser Permissions & Purpose Justification

bunIQ requests only the minimum necessary permissions under Google Chrome Manifest V3 specifications:

  • storage: Used strictly to save user theme preferences (Dark/Light), language settings (English/Amharic), cached marketplace stats, and the user's personal Google Gemini API key locally on their computer.
  • notifications: Used to deliver an optional native desktop notification when a marketplace catalog scan finishes in the background.
  • sidePanel: Enables users to open the AI Product Studio and view intelligence alongside active marketplace listings.
  • host_permissions (*://ye-buna.com/*, *://*.ye-buna.com/*): Grants access exclusively to read publicly visible listing attributes, prices, and timestamps on ye-buna.com to compute velocity metrics.
  • host_permissions (https://generativelanguage.googleapis.com/*): Grants direct browser-to-API communication with Google Gemini AI when the user enters their personal API key.

6. User Rights & Choices

You have full autonomy over your data:

  • Right to Inspect: You can view all saved information (API key, community handle, theme) directly within the extension Settings panel.
  • Right to Delete: You can instantly delete all locally stored data, reset all cached metrics, and clear your API key at any time using the in-app "Reset" feature or by uninstalling bunIQ.
  • Right to Opt-Out: Entering a Telegram handle or Google Gemini API key is completely optional. You may use the core outlier discovery features without providing either.
